# Exercise 1 — Git Workflow

## Purpose
Practice working with branches, commits, pull requests, and merging.

## Project
Patuvaj is a platform for discovering and booking tours.

## Workflow
1. Create a feature branch.
2. Make a change and commit it.
3. Push the branch to GitHub.
4. Open a pull request into main.
5. Merge the pull request.


## Why does a team work on branches and merge through pull requests, instead of everyone editing main directly?

team works on branches beacuse everyone can see someone's work and if something is wrong it wont get merged on master, also you dont won't break the project if you push to master
