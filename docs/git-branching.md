
# Lab 5.1 — Learn Git Branching

## Question 10

**Merge:** Merge combines the changes from one branch into another and preserves the branch history. I would choose merge when I want to integrate a completed feature branch into the main branch while keeping the original commit history.

**Rebase:** Rebase moves the commits of one branch onto the latest commit of another branch, creating a linear history. I would choose rebase to update my feature branch with the latest changes from main before merging it.
